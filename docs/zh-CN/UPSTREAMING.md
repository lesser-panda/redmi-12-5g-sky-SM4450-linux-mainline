# 上游化候选

本项目的东西还没有提交到上游。候选项，大致从易到难：

| 改动 | 位置 | 为什么该上游 | 剩余工作 |
|---|---|---|---|
| `lpass-rx-macro`：codec >= 2.5 的 DSM 时钟寄存器步长 | 补丁 0007 | 真 bug：受影响的 codec 上 INT2 扬声器通路永远拿不到时钟 | 写规范的提交信息，在第二台设备上测试 |
| `pwrseq-qcom-wcn`：最短断电时间 | 补丁 0006 | WCN 控制器需要约 0.5 秒断电才能复位 | 把延时做成属性，检查其他使用者 |
| 充电阈值的 UPower hwdb 条目 | `rootfs/61-sky-battery.hwdb` | 让 GNOME 为暴露阈值属性的设备显示充电上限 | 上游 UPower 没有通用规则；草稿保存在实验笔记（`UPSTREAM-upower-charge-limit-hwdb.md`） |
| `focaltech-ft8720-spi` 触摸驱动 + 绑定 | 补丁 0005 | 这颗控制器没有主线驱动 | 清理、拆分绑定、固件加载策略 |
| `fs1599` 功放驱动 | 补丁 0007 | FourSemi FS1599 没有主线驱动 | 绑定、去掉写死的默认场景、对照厂商源码复核序列 |
| 小米 sky 面板 | 补丁 0004 | 板级相关；只有配合设备树才有用 | 随设备树一起提交 |
| SM4450 平台部分（时钟、互连、SMMU、PAS、稳压器） | 补丁 0001 | 大多是 ROCKNIX 的工作；SM4450 支持已部分在上游 | 基于上游 SM4450 系列重新 rebase，署名原作者 |
| `qcom_battmgr` 小米软件充电上限 | 补丁 0008 | 厂商私有属性 | 大概率留在树外 |
| WCN6750 WiFi | 树外 | SNOC/ath11k 的限制在固件里 | 没有高通配合就没办法 |
