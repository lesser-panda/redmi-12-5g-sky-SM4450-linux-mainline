# 状态：哪些功能可用

在一台 Redmi 12 5G（23076RN4BI）上测试：Linux 7.3，Debian 13 + GNOME（Wayland），内核构建日期 2026-11-13。"已验证"指在手机上检查过，证据在[实验笔记](../lab-notebook/)；"用户确认"指有人亲眼看到或亲耳听到。

| 方面 | 状态 | 说明 |
|---|---|---|
| CPU、内存 | 可用 | 8 核，完整 8 GB（内存图案测试无不一致）。cpufreq 可用；22 个 SoC 温度区（CPU、GPU、DDR、modem、摄像头、视频）读数合理，并随负载测试变化（8 核满载约 60 °C，25 秒后回到 31 °C）；设备树里有 95 °C 降频触发点，但尚未达到 |
| 存储（UFS） | 可用 | HS-G3 x2，顺序读约 930 MB/s；内部闪存上的 ext4 根 |
| 显示 | 可用（用户确认） | DSI 面板 1080x2460（DSC），由 `msm` 驱动；背光为 KTD3136 |
| GPU | 可用 | Adreno 613，Mesa freedreno（GLES 3.2）与 turnip（Vulkan 1.0），GNOME 走 GPU 合成 |
| 触摸屏 | 可用（用户确认） | FocalTech FT8720，SPI，多点触控；每次复位后由主机下载固件 |
| WiFi | 可用 | WCN6750，走厂商 `qcacld` 驱动（树外构建）；WPA2，链路约 96 Mbit/s。主线 ath11k 驱动不了这个变体 |
| 蓝牙 | 可用 | UART2 上的 WCN3950 级芯片（主线 `hci_qca`）；需要 1 s 断电才能可靠复位 |
| 音频 | 可用（用户确认） | 扬声器（FS1599 功放，内核驱动）、听筒、底部麦克风，PipeWire + UCM。耳机孔、USB 声卡、蓝牙音频未测 |
| USB | 可用 | 设备模式（ACM + NCM gadget）、主机模式、DisplayLink 坞（HDMI 显示器、键盘、鼠标，经 evdi） |
| 屏幕旋转 | 可用（手动） | 没有可用的加速度计；顶栏菜单（竖屏、横屏左、横屏右），见 [DISPLAY.md](DISPLAY.md) |
| 触屏键盘 | 可用（用户确认） | GNOME 自带屏幕键盘 + 我们的布局：正交竖屏键盘（带 Esc/Tab/Ctrl/Alt/方向键）与 Planck 风格的横屏分体键盘（中间空隙可穿透点击），见 [KEYBOARD.md](KEYBOARD.md) |
| 电池、充电 | 可用 | 电量遥测、充电状态、软件充电上限（80 % 停充、75 % 恢复，经小米私有控制） |
| 按键、RTC | 可用 | 电源、音量加/减；PMIC RTC 不能被 Linux 写入（归别的子系统所有），读数是乱的；时钟靠 NTP，内核到 RTC 的同步已关闭 |
| 休眠 | 部分 | s2idle 与 deep 休眠可进入并恢复（RTC、电源键、音量加唤醒）；接着坞时手机有时 0.1–2 s 就自己醒来，原因未明。GNOME 默认不在空闲时休眠 |
| 稳定性 | 已验证 | 6.5 小时合成负载（CPU、内存压力、存储校验、GPU、WiFi），无内核错误、无 OOM、无数据错误 |
| 蜂窝基带 | 不可用 | 通话、短信、移动数据未开始（基带是 ADSP/modem 子系统上的固件） |
| 摄像头 | 不可用 | 未开始 |
| 传感器 | 不可用 | 加速度计、磁力计、光感、距离感应在 ADSP/TrustZone 持有的总线上；Linux 直接访问会让 SoC 失联。需要走 ADSP 传感器栈 |
| GPS、NFC、指纹、振动马达、耳机孔、FM | 未调查 | |
| 视频编解码 | 未开始 | 仅软件解码 |

## 启动方式

| 方式 | 是否写手机存储 | 用途 |
|---|---|---|
| `fastboot boot` 构建出的镜像 | 否 | 试内核、开发。重启回到 Android |
| 镜像放进 `recovery_b` 分区 | 一个分区 | `adb reboot recovery` 不接电脑启动 Linux；普通重启进 Android |
| Linux 根放在独立分区（`sda21`/`sda22`） | 给主闪存重分区（**清除 Android 数据**） | 桌面系统。没有它时同一个内核跑在内存根里 |

## 项目不声称什么

这是一次移植（bring-up），不是发行版：没有安装器、没有 OTA、没有受支持的升级路径，只有一台测试机。已知问题与规避办法见 [KNOWN-ISSUES.md](KNOWN-ISSUES.md)。
